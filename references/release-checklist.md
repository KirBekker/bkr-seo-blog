# Чек-лист выпуска SEO-статьи блога

Используй этот чек-лист только для статей блога. Для товарных страниц, категорий, лендингов и других типов страниц он не предназначен. Каждый пункт отмечай как «выполнено», «блокер», «требует проверки» или «не применимо» с коротким объяснением.

## До публикации

### Статья и SEO

- [ ] Это статья блога, а не страница другого типа.
- [ ] Регион и язык соответствуют ТЗ.
- [ ] Title и meta description заполнены и соответствуют фактическому содержанию.
- [ ] На странице один H1; H2/H3 образуют логичную иерархию.
- [ ] Основной запрос естественно использован в H1.
- [ ] Объём статьи и вхождения запроса сверены с исследованием по описанному методу.
- [ ] Короткий ответ стоит сразу после H1.
- [ ] FAQ содержит 3–5 релевантных вопросов; ответ на каждый обычно занимает 2–3 предложения и не более 60 слов.
- [ ] Имя, фамилия и должность/специализация автора подтверждены.
- [ ] Факты и утверждения подтверждены источниками проекта или разрешёнными официальными источниками.
- [ ] Внутренние ссылки ведут на существующие страницы с понятными анкорами.
- [ ] Внешние ссылки ведут только на собственные ресурсы или официальные государственные ресурсы по теме и региону.
- [ ] Для каждого смыслового блока подготовлен визуальный материал; отсутствие материала отмечено как блокер или явно согласовано пользователем.
- [ ] Для изображений подготовлены описательные alt и латинские имена файлов; запрос в alt используется только при смысловом соответствии.
- [ ] Растровые изображения подготовлены в сжатом WebP; HTML/SVG графика используется в нативном формате, если поддерживается CMS.
- [ ] Проверено отображение на мобильном и настольном экранах либо эта проверка отмечена как незавершённая.

### Техническая готовность и разрешение

- [ ] Canonical указывает на ожидаемый URL.
- [ ] Robots/noindex соответствует требуемому режиму индексации.
- [ ] Режим работы обозначен: черновик, подготовка выпуска или разрешённый выпуск.
- [ ] Получено явное разрешение пользователя на публикацию в production и на каждое запланированное внешнее действие.
- [ ] Необходимые доступы к CMS и инструментам вебмастера доступны.
- [ ] План возврата подготовлен, если он требуется проектом.

## После публикации

- [ ] Проверен опубликованный URL и фактический HTTP-код ответа.
- [ ] Страница открывается и содержит согласованный текст.
- [ ] Canonical соответствует ожидаемому URL.
- [ ] Robots и meta robots не запрещают индексацию, если она нужна.
- [ ] URL включён в актуальный sitemap, если проект использует sitemap.
- [ ] Внутренние и внешние ссылки открываются и ведут на нужные страницы.
- [ ] Визуальные материалы отображаются; alt, форматы и адаптивность проверены.
- [ ] Формы и события аналитики проверены, если входят в задачу.
- [ ] Отправка на индексацию выполнена только для применимых поисковых систем и при разрешении; записаны система, дата и результат.
- [ ] Фактический статус индексации отмечен отдельно, если его удалось проверить.

## Отчёт

Для каждого пункта укажи статус и подтверждение: URL, результат инструмента, дату либо причину, по которой проверка недоступна. Назови опубликованную версию, исправления, блокеры, владельца следующего действия и дальнейший шаг. Не помечай статью готовой, если остались блокеры.
