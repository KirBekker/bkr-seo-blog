# BKR SEO Blog

Codex skill для исследования, подготовки ТЗ, написания и проверки SEO-статей, предназначенных только для блога.

## Установка

Скопируйте папку навыка в каталог skills вашего Codex, сохранив структуру:

- SKILL.md
- agents/openai.yaml
- references/release-checklist.md

После установки используйте навык командой $bkr-seo-blog. Полная инструкция находится в [SKILL.md](SKILL.md).
